# Image Credits

The photographic assets in `static/images/museums/` and `static/images/experiences/`
depict Italian museums, cultural sites, and artworks. They are used solely to
illustrate this non-commercial university coursework project (Lab of Web
Technologies, AY 2025–26) and are not redistributed for any other purpose.

**Provenance disclosure:** these images were collected during development as
reference stock photography. Their individual original sources and licences were
**not recorded at the time of collection**. Rather than invent attributions, each
row below states `source not recorded` honestly. All subjects are widely
photographed public landmarks and public-domain artworks. If any rights holder
identifies an image that should not be used, it will be removed on request.
